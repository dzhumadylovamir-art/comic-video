# Comic Video

Программа для Mac: из страниц с японским текстом делает видео-слайдшоу 1920×1080 с японской озвучкой, фоновой музыкой и фото, вплавленным в страницы.

- Текст распознаётся прямо с картинок (Apple Vision, без интернета).
- Каждый слайд длится ровно столько, сколько звучит его озвучка.
- Музыка повторяется по кругу до конца видео и плавно затихает.
- Фото накладывается на весь кадр, а текст остаётся читаемым.
- Всё работает локально: ничего не отправляется в интернет, никаких подписок.

## Установка

Нужен Mac с macOS 13 или новее (Apple Silicon или Intel).

```bash
git clone https://github.com/dzhumadylovamir-art/comic-video.git
cd comic-video
./install.sh
```

Скрипт сам проверит и поставит, чего не хватает (инструменты разработчика, Pillow, ffmpeg), соберёт приложение и положит его в «Программы».

Отдельно поставьте **VOICEVOX** с [voicevox.hiroshiba.jp](https://voicevox.hiroshiba.jp) — это бесплатный японский синтез речи. Без него доступен только голос macOS.

Обновиться до новой версии:

```bash
cd comic-video && git pull && ./install.sh
```

## Как пользоваться

1. Запустите **Comic Video** — в браузере откроется окно программы.
2. Перетащите страницы (PNG, JPG, WebP или PDF). Порядок — по имени файлов, поэтому нумеруйте их: `001.png`, `002.png`…
3. Перетащите фото для фона и трек для музыки.
4. Настройте ползунки: «Размер страницы» увеличивает страницу (края могут обрезаться), «Растянуть по ширине» делает её шире. Кнопка «Показать кадр» покажет, как будет выглядеть слайд.
5. Нажмите **«Собрать видео»**. Если отметить «Сначала проверить распознанный текст», можно поправить ошибки распознавания перед озвучкой.

Готовые видео сохраняются в «Фильмы → ComicVideo». Чтобы выключить программу, нажмите «Закрыть программу» внизу окна.

## Голоса VOICEVOX

У каждого голоса VOICEVOX свои условия использования. Обычно в описании видео нужно указать персонажа, например `VOICEVOX:春日部つむぎ`. Условия каждого голоса — на сайте VOICEVOX.

## Из командной строки

```bash
python3 comic2video.py --images ПАПКА --overlay фото.jpg --music трек.mp3 --order ltr --out video.mp4
python3 comic2video.py --help   # все настройки
```
